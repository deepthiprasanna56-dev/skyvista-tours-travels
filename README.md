# ✈️ Aeroplane Tours & Travels Website

A modern, responsive, and luxury **Aeroplane Tours & Travels** web application built with **React**, **Vite**, and **Tailwind CSS**.

---

## 🌟 Key Features

1. **Attractive Navbar**:
   - Aeroplane brand mark and typography.
   - Smooth navigation with quick links to all sections.
   - 24/7 hotline concierge shortcut and instant "Book Trip" CTA.
   - Fully responsive slide-down mobile menu.

2. **Hero Section**:
   - Cinematic aeroplane visual backdrop with ambient gradient overlays.
   - Compelling value proposition and IATA accreditation badge.
   - Interactive live "Deal of the Week" card with instant booking.
   - Key trust metrics (120k+ Passengers Flown, 180+ Destinations, 4.95★ Rating).

3. **Flight Search & Booking Engine**:
   - Trip type selectors: **Round Trip**, **One Way**, and **Multi-City**.
   - Cabin Class selection (**Economy**, **Premium Economy**, **Business**, **First Class Suite**).
   - Dynamic airport selection with 180° interactive origin/destination swap button.
   - Departure and return date pickers with passenger count selector.
   - **Simulated Real-Time Flight Search**: Displays realistic flight results with airlines, flight numbers, direct/stop indicators, departure & arrival times, baggage allowances, and prices.
   - Instant "Book Flight" action that opens the interactive E-Ticket reservation modal.

4. **Popular Destinations**:
   - Category filtering: **All Destinations**, **Tropical Beaches**, **Mountain & Nature**, **Cultural Heritage**, and **Urban Wonders**.
   - High-definition travel photography, tags, flight durations, ratings, starting prices, and direct route booking.

5. **Flight Packages & Exclusive Offers**:
   - Curated all-inclusive holiday packages (Maldives Overwater Sanctuary, Swiss Alps Glacier Express, Tokyo & Kyoto Odyssey, Santorini Romance, Dubai Horizons, Bali Bliss).
   - Detailed amenity checklists (5★ hotels, airport transfers, gourmet dining, excursions).
   - Discount badges and pricing.

6. **Travel Services**:
   - Comprehensive services: Worldwide Flight Ticketing, Custom Tour Packages, Luxury Stays & Resorts, Visa & Travel Insurance, VIP Airport Concierge, and 24/7 Global Air Concierge.
   - Feature bullet tags and service numbers.

7. **About Us Section**:
   - Brand story and aviation ethos.
   - Milestone statistics counter (120,000+ passengers, 180+ destinations, 99.6% satisfaction rate).
   - Real passenger testimonials with verified ratings and avatars.

8. **Contact & Booking Form**:
   - Comprehensive inquiry form with validation and instant confirmation response.
   - Direct hotline phone number, email address, and office coordinates.
   - Interactive **FAQ Accordion** addressing common flight booking and cancellation questions.

9. **Interactive Booking & E-Ticket Modal**:
   - Pre-fills chosen flight or vacation package.
   - Captures passenger details, dates, passenger count, cabin class, and special requests.
   - Generates a **Simulated Electronic Boarding Pass** with unique reservation code (`SKV-XXXXXX`), verified IATA badge, and printable voucher view.

10. **Footer**:
    - Complete brand information, quick links, top international flight routes, payment partner badges, and a fare-drop newsletter subscription with instant feedback.

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```

### 4. Preview Production Build
```bash
npm run preview
```

## 📦 Deployment Instructions

### Option A: Deploy to Netlify
1. Create a free account at [Netlify](https://www.netlify.com/).
2. Push your repository to GitHub.
3. In Netlify, click **Add new site** > **Import an existing project** > **GitHub**.
4. Select your `skyvista-tours-travels` repository.
5. Set Build settings:
   - **Build command**: `npm run build`
   - **Publish directory**: `dist`
6. Click **Deploy site**!

### Option B: Deploy to Vercel
1. Create a free account at [Vercel](https://vercel.com/).
2. Connect your GitHub account and import the repository.
3. Framework preset will automatically detect **Vite**.
4. Click **Deploy**!
