# ✈️ Aeroplane Tours & Travels — Luxury Aviation & Expeditions

A modern, responsive, and luxury **Aeroplane Tours & Travels** web application built with **React 19**, **Vite**, and **Tailwind CSS**, inspired by high-end private aviation and first-class expedition experiences.

---

## 🌟 Key Features

1. **Executive 3D Intro Experience**:
   - VIP First-Class digital boarding pass card with real-time pre-flight telemetry progress.
   - Genuine Web Audio API **First Class Cabin Chime** sound synthesizer (zero external audio files).
   - Audio on/off toggle and `[ESC]` shortcut / skip intro pill.
   - Replay button in the header at any time.

2. **Interactive Boeing 787-9 Cabin Blueprint & Seat Selector**:
   - Interactive 1-2-1 seatmap blueprint (Suite 1A, 1D, 1G, 1K, 2A, Celestial SkyBar).
   - In-depth amenities breakdown: Lie-flat double beds, electrochromic panoramic dimming windows, Bang & Olufsen 4K cinema, and Dom Pérignon caviar service.
   - Click-to-reserve suite button that pre-fills the VIP Boarding Pass modal.

3. **Global Executive Aircraft Fleet Showcase**:
   - Flagship aircraft: **Gulfstream G700**, **Boeing 787-9 Dreamliner SkySuite**, and **Airbus A350-1000 Prestige**.
   - Performance gauges: Non-stop flight range, cruising speed (Mach), service ceiling altitude, and hourly charter estimates.

4. **3D Interactive Slide Carousel Showcase**:
   - Pure CSS 3D perspective coverflow with depth rotation (`rotateY`, `translateZ`).
   - Center slide highlighted with a glowing 24K gold halo ring.
   - Next/Previous controls, auto-play rotation, and instant reservation trigger.

5. **Executive Flight Search & Booking Engine**:
   - Multi-city expeditions, round trips, and one-way flights.
   - Cabin tiers: First Class Suite, Private Jet Charter, Executive Business, and Premium Economy.
   - Interactive airport swap with realistic flight routes, duration, baggage allowances, and live pricing.

6. **Curated Luxury Expeditions & Destinations**:
   - Category filtering: Tropical Islands, Alpine & Nature, Cultural Heritage, and Global Metropolises.
   - Cards with 3D hover lift, flight durations, ratings, and starting prices.

7. **Bespoke Travel Services & Concierge**:
   - 6 aviation services: Worldwide Flight Ticketing, Custom Tour Packages, Luxury Stays & Resorts, Visa & Diplomatic Clearance, VIP Airport Lounges, and 24/7 Global Air Concierge.

8. **Milestones & Verified Passenger Reviews**:
   - 120,000+ passengers flown, 180+ global destinations, 4.98★ verified rating.

9. **Diplomatic Contact & Booking Form**:
   - Customized flight quote requests with input validation and instant feedback.
   - Interactive FAQ accordion for travel policies and baggage guidelines.

10. **Electronic Boarding Pass Modal**:
    - Generates a simulated luxury boarding pass with reference code (`SKV-XXXXXX`), passenger details, and printable PDF voucher view.

---

## 🛠️ Tech Stack

- **React 19**
- **Vite 8**
- **Tailwind CSS v4**
- **Web Audio API** (Procedural cabin chimes & cockpit feedback)
- **Lucide-Style SVG Icons**

---

## 🚀 Getting Started

```bash
# 1. Install dependencies
npm install

# 2. Start local development server
npm run dev

# 3. Build for production
npm run build

# 4. Preview production build
npm run preview
```
